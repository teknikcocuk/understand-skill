# understand

Bir istemi uygulamadan önce anlamayı kendi başına bir iş olarak yapan Claude Code skill'i: istemi yorumlar, anladığını anlatır, "Bunu mu demek istedin?" diye sorar ve onay gelene kadar durur.

## Kurulum

Bu klasörü `~/.claude/skills/understand` altına kopyala:

```bash
git clone https://github.com/teknikcocuk/understand-skill ~/.claude/skills/understand
```

veya klasörü elle aynı yola kopyala.

## Kullanım

```
/understand <istem>
```

> Ask to be understood, not to be obeyed.
